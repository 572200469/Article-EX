1. **01_汇报文稿**：6页、约7分30秒的PPT文案；最终研究报告；逐条作品及数字证据表。
2. **02_图表**：三张终版图，PNG可直接粘贴到PPT，SVG用于矢量编辑。没有制作证据不足的主题效果图。
3. **03_分析数据**：A/B/C对照、期刊品牌、模型与主题分层统计、图表源数据、Token和费用估算。模型声称期刊与确认期刊分表。
4. **04_研究数据**：A组949个原始推荐位置与当前v3规范化数据库；B/C组50条实际推荐、55个JSON位置（含5个全null占位）与规范化证据。保留原始响应、一次发送凭据、分币种账本和冻结记录。
5. **05_证据与复核**：方法文献依据、coding-v2、当前期刊登记、24篇非随机正向控制及原刊证据、定向审核、学校知网待核验清单、完整性校验。

## 汇报时保留的限定

- 主实验192项：190成功回答、949实际位置；191份中央raw包含技术失败记录，序号171没有取得响应，不能补造。
- 定向试点16次均已发送：12成功、4技术失败、50实际推荐；另有5个全null占位不算论文。
- B确认1个大陆期刊译刊作品，原作者为美国学者，不作中国作者原创结论。
- C确认10个有英文题名的真实期刊作品，但25条C组推荐的文章级CJFQ收录全部待核实。
- unknown不等于不存在、非大陆或未收录；不作因果歧视、模型优劣或总体召回率结论。
- 软件预留CNY1.40/USD0.40不是实际账单；中转推理用量与单次估算差异见证据表。
