# 可用于汇报的发现与解释边界

1. 期刊品牌呈现集中在已确认子样本：Top3占533个期刊位置的42.8%，HHI=0.073。同刊不同作品与同作重复推荐已分别计数；不能据此断言全部949推荐的出版渠道结构。

2. 引文关系可展示为有限子样本描述：112个作品，Spearman ρ=0.419；经典主题ρ=0.428（n=53），数字主题ρ=0.421（n=59）。2000年代子组ρ=0.103（n=29），关联较弱，提示总体相关不代表各年代具有同样关系。年代分层仍有小样本和选择问题，不能称累计引文为标准化影响力，也不能推出高被引更容易入选。

3. 来源限定条件与原始题名表达呈现明显的描述性差异：同主题中文A为0/114含汉字题名，B为25/25、C为15/25。这里“明显变化”指观察计数，未进行显著性检验；不同重复和时间设计不支持来源限定的因果效应。

4. 题名中文化与中国出版成果的真实确认是两件事。B目前仅1个大陆独立归属来源支持的译载案例且待终审；C有10个可对应真作位置，但文章级CJFQ均未确认。不能把25个中文题名或“知网可查”声明当作已发现25篇本土真实成果。

5. 24篇真实中国期刊正向参照证明所选主题存在公开可核实的本土供给，但集合非随机、期刊较集中，不估计全国供给比例。192自然样本与16定向试点独立保留，来源证据unknown不计为境外或未收录。

Figure1、Figure3和方法附图可用于正式课堂汇报，需保留分母与pending标注；Figure4可作为证据覆盖与限制图，不能展示为B/C来源命中率已完成终审。Figure2仅在合格覆盖满足门槛时作为探索性子样本关联图展示，建议放补充页，并同列年代/主题分层结果。

“编辑把关—数据库把关—模型把关”可作为组织研究问题的框架；数据库覆盖、语言表达、平台路由、训练资源与经典文献累积引用等机制只能作为待检验的理论解释。现有数据不能拆分这些机制的作用，更不能认定因果歧视或给模型作总体优劣排名。未识别程度和官方/中转渠道差异均限制跨模型推断。
